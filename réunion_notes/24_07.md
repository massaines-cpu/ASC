# Analyse des résultats

Les courbes montrent :

-   la train loss diminue ;
-   la validation reste presque plate ;
-   apparition d'un début d'overfitting.

Selon Amel, ce comportement est normal avec un si petit nombre de
dyades.

Le vrai objectif est de construire un modèle capable de **généraliser à
une nouvelle dyade**.

------------------------------------------------------------------------

# Pourquoi généraliser ?

Le but final n'est pas seulement d'interpréter les régions cérébrales.

On souhaite aussi qu'une nouvelle dyade, jamais vue pendant
l'entraînement, puisse être correctement classifiée.

Le modèle ne doit donc pas apprendre les données par cœur.

------------------------------------------------------------------------

# Remarques sur l'architecture actuelle

Architecture actuelle :

-   Flatten
-   Couche linéaire

Cette architecture est jugée **trop simple**.

Après le Flatten, chaque participant est représenté par environ :

32 × 5120 = 163 840 valeurs.

Le modèle essaie donc de classifier directement un vecteur extrêmement
grand, ce qui favorise le surapprentissage.

La pipeline est correcte, mais **le modèle doit maintenant évoluer**.

------------------------------------------------------------------------

# Cross Validation

La prochaine étape est de mettre en place une **Leave-One-Dyad-Out Cross
Validation**.

Principe :

-   une dyade est gardée pour la validation ;
-   toutes les autres servent à l'entraînement ;
-   on répète l'expérience pour chaque dyade.

Pour chaque fold :

-   produire les courbes Train / Validation ;
-   comparer les comportements entre les différentes dyades.

------------------------------------------------------------------------

# Early Stopping

Une fois la Cross Validation terminée :

ajouter un **Early Stopping**.

Principe :

-   surveiller la validation loss après chaque époque ;
-   arrêter automatiquement lorsque celle-ci ne s'améliore plus pendant
    un certain nombre d'époques.

Objectif :

-   éviter le surapprentissage ;
-   arrêter l'entraînement au bon moment.

------------------------------------------------------------------------
