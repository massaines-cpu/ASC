## 3. Modifier temporairement la logique "dyade"

Le pipeline actuel considère qu'un exemple est composé de :

```text
Participant A
+
Participant B
+
1 label
```

Pour la première expérience (**Yeux ouverts / Yeux fermés**), Amel souhaite travailler au niveau du **participant** et non de la dyade.

L'objectif est d'augmenter le nombre d'exemples disponibles.

Au lieu de considérer :

```text
1 dyade = 1 exemple
```

on considérera :

```text
Participant A = 1 exemple

Participant B = 1 exemple
```

avec le même label.

> Cette modification est uniquement destinée à la première expérience.  
> Le pipeline diadique sera réutilisé par la suite pour le véritable modèle Multi-Brain.


Par exemple :

```text

```

Cette solution permet de conserver le pipeline actuel tout en ajoutant une version spécifique pour les expériences non diadiques.

## 6. Remplacer plus tard le découpage Train / Validation / Test

Le découpage actuel est acceptable pour commencer.

En revanche, il ne sera pas utilisé pour l'évaluation finale.

### À terme : utiliser une Cross Validation

Le principe est :

- sélectionner une dyade comme ensemble de validation ;
- entraîner le modèle sur toutes les autres ;
- recommencer avec une autre dyade ;
- calculer la moyenne des performances.

L'objectif est d'obtenir une estimation plus fiable des performances du modèle.

Un simple découpage train/test peut produire des résultats très différents selon les dyades choisies.

## 8. Comprendre le Batch Size

Une partie importante de la réunion a porté sur le fonctionnement du **batch size**.

### Sans batch

Le réseau :

- prend un seul échantillon ;
- calcule une erreur ;
- met immédiatement à jour ses poids.

Cette méthode est très instable.

### Avec un batch

Le réseau :

- prend plusieurs échantillons ;
- calcule une erreur moyenne ;
- met à jour les poids une seule fois.

Le **batch size** correspond donc au nombre d'échantillons utilisés avant une mise à jour des poids.

Le choix de cette valeur est expérimental.

Il n'existe pas de valeur universelle.
